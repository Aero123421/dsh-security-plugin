# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Translations, including Japanese, are available at <https://www.contributor-covenant.org/translations/>.

## In short

- Be respectful and welcoming. Assume good intent, and remember that many participants write in a second language.
- Give and accept constructive feedback. Critique code and ideas, not people.
- Harassment, discrimination, personal attacks, sexualized language or imagery, trolling, and publishing others'
  private information are not acceptable, in any project space or when representing the project.
- This is a security project: do not use project spaces to share exploits against third parties, real credentials,
  or other people's private code.

## Scope

This applies in all project spaces (issues, pull requests, discussions, reviews, chat) and when someone represents
the project in public.

## Reporting

Report unacceptable behavior privately to the maintainers. Use GitHub's
[private vulnerability reporting](https://github.com/Aero123421/dsh-security-plugin/security/advisories/new) form
with a title starting with "Conduct:", or contact a maintainer directly. Reports are handled confidentially.
Maintainers who are involved in a report will not take part in handling it.

Maintainers may take any action they consider appropriate, following the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, or permanent ban.
